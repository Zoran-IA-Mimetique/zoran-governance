# Zoran Coherence Skill 14.0.0 — audited candidate

This release is a hardening successor to the byte-preserved v13.3.0 archive. It is intentionally labelled `audited-candidate`, not externally certified.

## Closed failure classes

- invalid skill discovery metadata and monolithic instructions;
- optional/duplicate terminal-control bypasses and permissive boolean coercion;
- non-finite numeric inputs, negative-defect compensation, and pass-by-omission paths;
- shallowly frozen policies, frames, schemas, profiles, and family registries;
- receipts that did not bind complete requests, evidence, limits, or provider outcomes;
- source-ID coercion, duplicate-content independence inflation, and contradiction truncation;
- ZMOS metadata tamper, concurrent-writer snapshot defects, unbound recalls, unsafe permissions, and optional quota support;
- mirror path, size, manifest, post-verification, and rollback weaknesses;
- quadratic next-unread search in large read-progress objects;
- non-reproducible packaging, stale self-certification artifacts, absent dependency split, SBOM, and provenance.

## Deliberately trace_pending

- external reviewer identity and organizational independence;
- signed commits, Sigstore/transparency evidence, SLSA level, and dependency artifact hashes;
- real host wrapper that chains pre-chat, polymorphic selection, evaluation, ZMOS promotion, and terminal trust roots;
- open-world semantic accuracy and prompt-injection resistance beyond the registered lexical detector;
- host persistence, connectors, CI alarms, and clean isolated dependency installation.

See `references/security-limitations.md` and `references/evaluation-and-release.md` before promotion.
